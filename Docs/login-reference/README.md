# Login screen — original reference screenshots

Visual ground truth for issue #932 (Interlude login screen rebuild). These are
captures of a **clean retail Interlude client** login screen — NOT generated, NOT
mockups. Side-by-side screenshots in every login UI/scene PR compare against
these.

## interlude-login-retail-1440p.jpg

- Source: Steam Workshop item 3382235574, "Lineage 2 - Interlude 1440p" by Ouro
  (Wallpaper Engine wallpaper of a retail Interlude client login screen).
- Download URL:
  `https://images.steamusercontent.com/ugc/18673820420390097/136495FC2FF8B170DC8A365886DBC736E60E20C6/`
- Workshop page:
  `https://steamcommunity.com/sharedfiles/filedetails/?id=3382235574`
- Downloaded: 2026-11-22.
- Format: 1013x1013 JPEG. Caveat: this is a square center-crop of a 16:9 capture —
  the side menu (New Account / Lost Account / Options / Production Team / Replay,
  anchored bottom-right in the original) is cut off. Menu geometry source of
  truth is `l2-unity/docs/ui-original/Login.json` (recovered from `nwindow.dll`).
- Visible and usable for scene comparison: forest vista composition, mossy arch
  (lobby_back mesh), gnarled trunk on the right, ferns / flowers / mushrooms,
  god rays through foliage, L2 logo top-center, ID/PWD panel centered, overall
  lighting/fog mood.
